# CodeAlpha_StockPortfolioTracker

Simple stock portfolio tracker built for the **CodeAlpha Python Programming Internship (Task 2)**.

## Features
- User enters stock names and quantities
- Hardcoded dictionary of stock prices (AAPL, TSLA, GOOGL, MSFT, AMZN)
- Displays a formatted table and the total investment value
- Optionally saves the result to a `.txt` and/or `.csv` file
- Input validation for unknown stocks and invalid quantities

## Concepts Used
dictionary, input/output, basic arithmetic, file handling

## How to Run
```bash
python stock_tracker.py
```

## Sample
```
Stock name (or 'done'): AAPL
Quantity of AAPL: 10
Stock name (or 'done'): TSLA
Quantity of TSLA: 5
Total Investment: $3050.00
```
